# Arciin v1.1.3 — Universal Search & Interface Refinement

The search box at the top now searches everything, imported links keep their
real names and show real previews, and the panels beside your libraries are
compact and consistent. No database migration; nothing is removed.

## What's new

### Universal Search

- **The top search is a real search.** Press **⌘K / Ctrl+K** anywhere (or
  click the search box) and type. Files, folders, libraries and pages come
  back together, grouped, best match first.
- **Matches by meaning, right there.** With semantic search on (v1.1.2),
  files found by what they show or say appear in the same list, marked
  *Matched by meaning* or *Related by meaning*. An exact name always comes
  first; a few places are kept for meaning so loose name matches cannot
  crowd them out. No scores are shown.
- **Fast first, then smarter.** Name matches appear as you type; matches by
  meaning join a moment later. Typing on cancels the old request.
- **Honest status.** While the index is building, one quiet line says how far
  it has got ("412 / 817 indexed"); if Ollama is stopped, search says it is
  showing name matches. With semantic search off, nothing nags.
- **Keyboard first.** ↑ ↓ to move, Enter to open, Shift+Enter to reveal a
  file in its folder, Esc to close — focus returns to the search box.
- **Opens in place.** A file opens on its library or folder page with the
  inspector already showing it; *View all results* opens All Files with your
  search applied.
- **Same privacy rules.** Search shows only what you could already browse:
  nothing deleted, archived or hidden, nothing inside a locked folder you
  have not unlocked, and none of the legacy Computer Backup folder trees.

### Imports keep their names

- **Real titles.** A YouTube import is saved as *Building a Data Center —
  Redundancy Explained.mp4*, not *dQw4w9WgXcQ.mp4* or *preview.mp4*. MP3 and
  M4A audio extractions keep the same title. The title comes from the source
  itself — the item you picked, yt-dlp's metadata, or the page — never from
  text a browser sends.
- **Safe on every disk.** Titles are made into filenames that keep accents,
  other scripts and emoji, but never contain path separators, `..`, reserved
  characters or device names. Files are still stored by checksum; only the
  name you see changes.
- **Searchable.** The title is part of what semantic search reads.
- **Existing imports are untouched.** Nothing is renamed during the update.

### Import thumbnails

- **Real previews** in *Import from link*: each item found on a page or in a
  playlist shows its thumbnail. Your server fetches it — your browser never
  contacts the third-party site — with the same protections as an import
  (public addresses only, every redirect checked, size and type limits).
  Where no preview exists, a clean icon stands in.

### Redesigned panels

- **Import from link** is a compact floating panel: link, preview, download
  options and supported sources, with the Import button always in reach. No
  more tall empty column.
- **Asset inspector** follows the same shell: preview first, then the file's
  type, library and folder, its details, and actions at the bottom. Edit,
  Assist, Move and Share share one header and one *Back to Overview* control.
  The library's own Edit, Move, Share and New folder panels match.

### Polish

- **Database:** the Folders card shows *current*, *legacy computer* and
  *deleted* counts; the Folders table leads with folder, library and a
  classification badge, filters show their counts, and raw ids are one
  click away.
- **Storage audit:** a disk bar, stat cards (used, free, managed files,
  backups, trash, failed uploads, orphan candidates, Ollama models) and a
  *Where the space goes* breakdown. Still read-only.
- **Notifications:** unread rows are clearly marked, the header says how many
  are unread, pages say *Showing 11–20 of 40*, and a cleared inbox points to
  Activity.
- **Sidebar:** orange active marker, stronger text contrast, visible keyboard
  focus, and libraries stay reachable when the sidebar is collapsed.
- **Accessibility and motion:** labelled controls in the collapsed sidebar,
  combobox/listbox semantics in search, and reduced motion respected
  everywhere.

## For operators

- **No migration.** No database or storage change is needed.
- **New API routes:** `GET /api/search`, `GET /api/search/files` (any signed-in
  user or an `assets:read` key), and
  `GET /api/imports/inspections/:inspectionId/items/:itemId/thumbnail`
  (the user who ran the inspection).
- **Security hardening:** the server-side image fetch used for AI covers now
  also refuses private IP literals and hex-form IPv4-mapped IPv6 addresses.
- **Existing imports:** a read-only check on the release server found
  56 imported files, none with a source title and 25 with opaque names.
  They are left as they are; a metadata-only, owner-triggered rename is
  planned for a later release.

## Not in this release

- Renaming existing imports from their source metadata.
- Individual notification dismissal.
